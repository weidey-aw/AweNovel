# AweNovel · Galgame 社区

> 一个属于 Galgame 爱好者的社区网站：收录游戏图鉴、分享攻略评测、交流资源。

## 功能一览

### 前台（访客 / 社区用户）

- **游戏库**：按会社、标签、发售时间筛选，支持热度、评分、发布时间等排序；游戏详情包含简介、截图、制作阵容、评分与评论。
- **文章**：资讯 / 评测 / 攻略三类内容，支持 Markdown 图文与代码块；登录后可直接在站内写文章。
- **资源**：社区分享的网盘、磁力、直链等多来源资源，支持提取码与解压码；同时展示正版购买入口。下载会消耗积分。
- **个人中心**：积分与等级、每日签到、站内消息、我的收藏、关注列表、资料与密码管理。
- **收藏**：游戏与文章一键收藏，可在个人中心按类型查看与取消。
- **资源反馈**：遇到资源失效、无法运行、缺少补丁等问题，可直接反馈给上传者，并收到站内消息回复。
- **AI 看板娘**：DeepSeek 鲸鱼娘常驻页面右下角，可闲聊、问游戏，支持 Live2D 动态立绘；没有立绘资源时会自动切换为静态形象。
- **主题**：内置「白蓝」与「暗夜色」两套配色，前台与后台均可一键切换并记住选择。

### 后台（管理员 / 运营）

- **仪表盘**：站点数据概览与快捷入口。
- **内容运营**：游戏、会社、标签、文章、资源、评论管理，以及待审核内容的审核与上下架。
- **系统管理**：用户、角色、菜单、字典、参数、通知公告。
- **系统监控**：在线用户、定时任务、服务状态、缓存与操作日志。

## 快速体验

> 仅供本地体验。需要提前准备 **JDK 17+、MySQL、Redis**；数据库初始化脚本由维护者单独提供（不随仓库发布，见部署文档）。

1. 初始化数据库（导入维护者提供的初始化脚本）；
2. 构建并启动后端服务；
3. 安装依赖并分别启动前台与管理端开发服务器。

启动后：

| 端 | 默认端口 |
|---|---|
| 前台 | 5173 |
| 管理后台 | 5174 |
| 后端接口 | 9090 |

默认管理员账号：`admin` / `admin123`（首次使用后请立即修改）。

更完整的部署与运行说明见 [`docs/部署文档.md`](docs/部署文档.md)。

## 项目结构

```
AweNovel/
├── weidey-admin/         # 启动入口与管理端接口
├── weidey-framework/     # 框架与安全配置
├── weidey-system/        # 系统管理模块
├── weidey-common/        # 公共工具与基础能力
├── weidey-AweNovel/      # 社区业务（游戏、文章、资源、用户、AI 等）
├── web-ui/               # 前端：用户端 web + 管理端 admin + 共享包 shared
└── docs/                 # 项目文档（仅本地维护）
```
